# P2 CNC Request-for-Quotation Package

Quote one Rev-A prototype set plus separate unit prices for a second set. Quote
P2-120 through P2-122 first as a coupon lot and the remaining custom parts as a
production lot released only after coupon approval.

## Files and precedence

Use the PDFs for dimensions, GD&T, notes, material, finish, and inspection. Use
STEP for 3D form and DXF for flat profiles. CSV cam profiles are independent
inspection data. STL is preview-only. All supplied files must match the package
SHA-256 list.

## Requested quote breakdown

1. POM-C coupon lot: P2-120 and P2-121.
2. POM-C production cams: P2-101 and P2-102.
3. 6061-T6 milled parts: P2-103 through P2-109, P2-122, and P2-124 through
   P2-126, with anodize shown separately.
4. 303 stainless turned parts: P2-110 through P2-113, P2-123, P2-127, and
   P2-128.
5. Laser/router parts: P2-115 through P2-119.
6. Inspection report for interfaces I-01 through I-05 and shaft runout.
7. Material certificates, programming/setup charges, shipping, tax, lead time,
   quote validity, and remake policy as separate entries.

## Supplier questions

- Can you hold a 0.05 mm free-form profile relative to a 32 H7 bore in POM-C?
- What stock conditioning and stabilization do you use before final profiling?
- Will the same machine setup finish pilot, datum hole, and profile?
- Can you return measured profile data or a CMM report at 16 date stations?
- What bearing-fit masking method is used during anodize?
- Are any CAD features ambiguous or economically dominant?

No substitution, profile smoothing, unit conversion, or unexplained CAM
optimization is authorized. Supplier shall request disposition before deviating.
